# Weather GUI 🌤️

A simple weather application built with **Python**, **Tkinter**, and the **OpenWeatherMap API**.

The app allows users to enter a city and retrieve its current temperature and weather conditions through a simple graphical interface.

## Features

* Search for weather by city
* 🌡️ Display current temperature in Fahrenheit
* ☁️ Display current weather conditions
* 🖥️ Simple graphical user interface
* 🔌 Uses a real weather API
* 📦 Uses JSON data from the API

## Technologies Used

* **Python**
* **Tkinter** — GUI
* **Requests** — API requests
* **OpenWeatherMap API** — Weather data

## Installation

Clone the repository:

```bash
git clone https://github.com/Phandom780/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Install the required package:

```bash
pip install requests
```

Tkinter is included with most Python installations.

## API Key Setup

This project requires an OpenWeatherMap API key.

Create an API key and then add it to the Python file:

```python
API_KEY = "YOUR_API_KEY"
```

**Do not upload your real API key to GitHub.** For a public repository, use an environment variable or another secure method to store it.

## How to Use

1. Run the Python program.
2. Enter a city into the input box.
3. Click **Get Weather**.
4. The application will display the city's current temperature and weather conditions.
